# အကိုးအကားများ (Reference) {: #reference }

Lab များ လက်တွေ့ပြုလုပ်နေစဉ် ဒုတိယ tab အနေဖြင့် ဖွင့်ထားသင့်သည့် အချက်အလက်များ။

---

<div class="grid cards" markdown>

-   **IP လိပ်စာခွဲဝေမှု အစီအစဉ် (IP addressing plan)**

    ---

    Lab တစ်လျှောက်လုံးတွင် အသုံးပြုသော စံနှုန်းသတ်မှတ် IP လိပ်စာများ — loopbacks, point-to-point links, VLANs နှင့် VNIs များ။ လိပ်စာအသစ် မသတ်မှတ်မီ ဤနေရာတွင် စစ်ဆေးပါ။

    [ဖွင့်ရန် →](ipplan.my.md)

-   **Verification Cheatsheet**

    ---

    အလွှာအလိုက် စုစည်းထားသော အဓိကကျသည့် `show` command များနှင့် ကောင်းမွန်သောအခြေအနေတွင် တွေ့ရမည့် ရလဒ်များ။

    [ဖွင့်ရန် →](verify-cheatsheet.my.md)

-   **Validation Runbook** &nbsp; <span class="nf-badge plan">မူကြမ်း</span>

    ---

    Fabric များကို စစ်ဆေးအတည်ပြုခြင်းဆိုင်ရာ လက်တွေ့မှတ်စုများ။ အချောသတ်မဟုတ်သေးသော်လည်း အလွန်အသုံးဝင်သောကြောင့် ဖော်ပြထားပါသည်။

    [ဖွင့်ရန် →](validation-runbook.my.md)

</div>

!!! tip "Platform ဆိုင်ရာ သတိပြုဖွယ်ရာများသည် Lab များတွင် တိုက်ရိုက်ပါရှိသည်"
    cEOS ဆိုင်ရာ သတိပြုရန်အချက်များ — `ethN` အမည်ပေးနည်း စည်းမျဉ်း၊ တိတ်ဆိတ်နေသော `docker exec` ချို့ယွင်းချက်၊ boot race ပြဿနာများ — ကို ဤနေရာတွင် စုစည်းမထားဘဲ သင်ကြုံတွေ့ရမည့် သက်ဆိုင်ရာ lab တစ်ခုချင်းစီ၏ troubleshooting ဇယားများတွင် တိုက်ရိုက် ထည့်သွင်းဖော်ပြထားပါသည်။
