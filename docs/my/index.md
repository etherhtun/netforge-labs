# NETFORGE LABS (မြန်မာဗားရှင်း)

**ကွန်ရက်နည်းပညာကို လက်တွေ့ကိုယ်တိုင် တည်ဆောက်ရင်း လေ့လာပါ။** Arista cEOS စနစ်များပေါ်တွင် Real-World Network Fabrics များကို တည်ဆောက်ပါ၊ စနစ်များကို ရည်ရွယ်ချက်ရှိရှိ ပြိုလဲစမ်းသပ်ပါ (break it on purpose)၊ Configuration တစ်ကြောင်းချင်းစီ၏ နောက်ကွယ်ရှိ အရေးပါပုံ (*why*) ကို သဲသဲကွဲကွဲ နားလည်စေမည်။

မိမိတက်လှမ်းလိုသည့် အင်ဂျင်နီယာ အထူးပြုလမ်းကြောင်းများကို စိတ်ကြိုက်ရွေးချယ်လေ့လာနိုင်ပါသည် - **AI & Hyperscale Architecture**၊ **Network SRE & Observability**၊ **Cybersecurity & DevSecOps**၊ **NetDevOps**၊ **Low-Latency Finance**၊ သို့မဟုတ် **TPM System Design**။

## 🛠️ စတင်လေ့လာနည်း (Quick Start)

1. **Lab Setup**: [macOS OrbStack](../getting-started/lab-setup-macos.md) သို့မဟုတ် [Linux Docker](../getting-started/containerlab.md) ကို ထည့်သွင်းပါ။
2. **Containerlab စတင်ပါ**: `clab deploy -t topology.clab.yml` တစ်ကြောင်းတည်းဖြင့် Multi-node Arista cEOS topology ကို ချက်ချင်း run နိုင်ပါသည်။
3. **Verification စစ်ဆေးပါ**: ပေးထားသော automated verification script များကို run ပြီး State များကို အတည်ပြုပါ။
