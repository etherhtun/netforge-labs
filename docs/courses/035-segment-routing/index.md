# Phase 3.5 · Segment Routing

📖 **Status: Planned**

## Syllabus

This phase dives into how hyper-scalers (FAANG) and modern service providers steer traffic across global backbones.

- **SR-MPLS:** Segment Routing over an MPLS data plane.
- **SR-PCE:** Centralized Path Computation Elements for traffic engineering.
- **Ti-LFA:** Topology Independent Loop-Free Alternate for sub-50ms failover.
- **SRv6 Basics:** Routing using IPv6 extension headers.
