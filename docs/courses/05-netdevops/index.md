# Phase 5 · NetDevOps (Network Automation)

📖 **Status: Planned**

## Syllabus

This phase covers how to treat network infrastructure as code, a critical skill for Site Reliability Engineering (Network) roles.

- **Infrastructure as Code (IaC):** Defining network state in code.
- **NetBox:** Building a Source of Truth.
- **Python (Nornir/Netmiko) & Ansible:** Programmatically deploying fabrics.
- **CI/CD Pipelines:** Validating ECMP paths and configurations before deployment.
