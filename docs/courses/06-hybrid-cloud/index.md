## Syllabus

This phase covers extending the on-premise fabric into public cloud environments.

- **AWS Transit Gateway (TGW):** Connecting VPCs and on-prem networks.
- **BGP over DirectConnect:** High-speed private cloud connectivity.
- **IPSec & SD-WAN:** Secure overlay networks over the internet.
