# Phase 2 · BGP-DIA & Internet Edge

📖 **Status: Planned**

## Syllabus

This phase covers how to connect a large-scale network to the outside world safely and efficiently.

- **Multi-homing:** Connecting to multiple transit providers.
- **RPKI:** Securing BGP routing from hijacks.
- **Peering:** Setting up private peering and IXP connections.
- **NAT / CGNAT:** Managing address translation at the edge.
