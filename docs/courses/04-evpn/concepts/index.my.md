# သီအိုရီကို အရင်လေ့လာပါ၊ ထို့နောက် Lab စမ်းသပ်ပါ {: #study-first-then-lab }

ဤသည်မှာ **သီအိုရီလမ်းကြောင်း (theory track)** ဖြစ်ပါသည်။ Lab လက်တွေ့မလုပ်မီ အစီအစဉ်အတိုင်း ဖတ်ရှုလေ့လာပါ — ၎င်းသည် စိတ်ကူးပုံစံ (mental model) ကို တည်ဆောက်ပေးပြီး lab config များကို ကူးထည့်ရုံသက်သက်မဟုတ်ဘဲ အဓိပ္ပာယ်ရှိရှိ နားလည်စေပါမည်။

သင်ခန်းစာတစ်ခုချင်းစီသည် တိုတိုတုတ်တုတ်ဖြစ်ပြီး အဆုံးတွင် **မိမိကိုယ်ကို ပြန်လည်စစ်ဆေးသည့် မေးခွန်းများ** ပါဝင်ပါသည်။ ထိုမေးခွန်းများကို ဖြေဆိုနိုင်ပါက ရှေ့သို့ ဆက်သွားပါ။

## အရာအားလုံးတွင် သတိချပ်ရမည့် အဓိက သဘောတရားတစ်ခု {: #one-mental-model-to-carry-through-everything }

> **VXLAN သည် လှိုဏ်ခေါင်း (tunnel) ဖြစ်သည်။ EVPN သည် ဦးနှောက် (brain) ဖြစ်သည်။**
> VXLAN သည် L3 ကွန်ရက်တစ်ခုကို ဖြတ်သန်း၍ L2 frame များကို သယ်ဆောင်ပေးသည်။ EVPN သည် switch တစ်ခုချင်းစီအား host တစ်ခုစီ မည်သည့်နေရာတွင် ရှိနေကြောင်း ပြောပြပေးသည့် control plane ဖြစ်သောကြောင့် ထို tunnel များကို broadcast flooding အစား သိရှိထားသော ဗဟုသုတ (knowledge) ဖြင့် တည်ဆောက်ပေးပါသည်။

ထိုစကားစုကို စိတ်ထဲတွင် အမြဲမှတ်ထားပါ။ သင်ခန်းစာတိုင်းသည် ထိုအခြေခံသဘောတရားပေါ်တွင် ချိတ်ဆက်တည်ဆောက်ထားခြင်း ဖြစ်ပါသည်။
