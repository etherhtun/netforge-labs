# BGP အခြေခံသဘောတရားများ (Concepts)

Lab များတစ်ခုတည်းဖြင့် သဘောပေါက်နားလည်ရန် မလွယ်ကူသော BGP ၏ အဓိက အစိတ်အပိုင်းများ — State machine၊ attributes များ၊ best-path algorithm နှင့် BGP ကို သာမန် routing protocol တစ်ခု မဟုတ်ဘဲ policy protocol တစ်ခု ဖြစ်လာစေသည့် policy tooling များအကြောင်း အကျဉ်းချုပ် ရှင်းလင်းချက်များ ဖြစ်သည်။

ဤအကြောင်းအရာများကို [Lab 01](../lab-01-ebgp-ibgp.md) မစတင်မီ၊ Lab နှင့် တွဲဖက်၍ သို့မဟုတ် ပြန်လည်လေ့ကျင့်မှုအဖြစ် ဖတ်ရှုနိုင်ပါသည်။ ဖော်ပြထားသော output များကို လက်တွေ့လည်ပတ်နေသော lab fabric မှ တိုက်ရိုက်ဖမ်းယူထားခြင်း ဖြစ်သည်။

## စာတစ်ပိုဒ်တည်းဖြင့် အကျဉ်းချုပ်

BGP သည် အတိုဆုံးလမ်းကြောင်းကို ရှာဖွေပေးခြင်း မဟုတ်ပါ — ၎င်းသည် **သင်လိုချင်သည်ဟု ညွှန်ကြားထားသော** လမ်းကြောင်းကို ရှာဖွေပေးခြင်း ဖြစ်သည်။ Route တိုင်းတွင် attributes အစုံလိုက် ပါဝင်ပြီး; သင်၏ policy က ၎င်းတို့ကို သတ်မှတ်ဖတ်ရှုပေးကာ; ပုံသေ algorithm တစ်ခုက ၎င်းတို့ကို သတ်မှတ်ထားသော အစဉ်အတိုင်း နှိုင်းယှဉ်၍ အနိုင်ရသူကို ရွေးချယ်ပေးသည်။ Attributes များနှင့် ၎င်းတို့ကို နှိုင်းယှဉ်သည့် ဦးစားပေးအစဉ်လိုက်ကို နားလည်သဘောပေါက်ပါက BGP သည် သင့်အတွက် လျှို့ဝှက်ဆန်းကြယ်မှု မရှိတော့ပေ။
