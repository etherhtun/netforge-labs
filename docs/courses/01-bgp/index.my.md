# Phase 1 — BGP Fundamentals & Policies

> ✅ **Labs 01–04 အားလုံးကို** Arista cEOS 4.32.0F ပေါ်တွင် အောင်မြင်စွာ စမ်းသပ်အတည်ပြုပြီး ဖြစ်သည်။

ဤသင်ရိုးရှိ အခြား protocols အားလုံးသည် *အမြန်ဆုံး/အနီးဆုံး လမ်းကြောင်း (shortest path)* ကို ရှာဖွေပေးပါသည်။ BGP သည် *သင်က မည်သည့်လမ်းကြောင်းကို လက်ခံမည်၊ မည်သည့်လမ်းကြောင်းကို ကြေညာမည်* ကို ဆုံးဖြတ်ပေးပါသည် — အချုပ်အားဖြင့် routing protocol ပုံစံ ယူထားသော policy protocol စစ်စစ် ဖြစ်ပါသည်။

ထိုခြားနားချက်က ၎င်းနှင့်ပတ်သက်သော အရာအားလုံးကို ရှင်းပြပေးပါသည်။ BGP သည် OSPF ထက် convergence နှေးကွေးသော်လည်း အင်တာနက်ကွန်ရက် တစ်ခုလုံးအထိ ကြီးမားစွာ scale ချဲ့နိုင်ပြီး စီးပွားရေးဆိုင်ရာ စည်းမျဉ်းများကို configuration အဖြစ် ရေးဆွဲချမှတ်နိုင်စေပါသည်။

## BGP သည် အဘယ်ကြောင့် ကွဲပြားသနည်း

| အချက်အလက် | IGP (OSPF, IS-IS) | BGP |
|---|---|---|
| အဓိက ဦးတည်ချက် | အနီးဆုံးလမ်းကြောင်း (shortest path) | **မူဝါဒ (Policy)**၊ ပြီးမှ လမ်းကြောင်း |
| အတိုင်းအတာ | အဖွဲ့အစည်းတစ်ခုအတွင်း | အဖွဲ့အစည်း အချင်းချင်းကြား |
| Metric | ကုန်ကျစရိတ် (cost/bandwidth) | မိမိစိတ်ကြိုက် ထိန်းချုပ်နိုင်သော attributes များ |
| Convergence | စက္ကန့်ပိုင်းအတွင်း | တမင်တကာ ပိုမိုနှေးကွေးစေသည် |
| Scale ပမာဏ | လမ်းကြောင်း ထောင်ဂဏန်း | ကမ္ဘာ့အင်တာနက် လမ်းကြောင်း ~၁,၀၀၀,၀၀၀ |
| ယုံကြည်စိတ်ချရမှု | Router အားလုံး မှန်ကန်သည်ဟု ယူဆ | **Peers များသည် မလိုလားအပ်သော အရာများ ပို့လာနိုင်သည်ဟု ယူဆ** |

နောက်ဆုံးအချက်သည် အရေးအကြီးဆုံး ဖြစ်သည်။ IGP သည် ပါဝင်သူအားလုံး ရိုးသားသည်ဟု ယူဆသည်။ BGP သည် မိတ်ဖက်စက်သည် မတူညီသော စီးပွားရေးအကျိုးစီးပွားရှိသည့် အခြားကုမ္ပဏီတစ်ခုဟု ယူဆထားသောကြောင့် မည်သည့်အရာကိုမျှ အလိုအလျောက် လက်မခံဘဲ အရာအားလုံးကို filter ပြုလုပ်နိုင်အောင် ဖန်တီးထားပါသည်။

## မဖြစ်မနေ သတိပြုရမည့် အခြေခံ အယူအဆ

**eBGP နှင့် iBGP သည် စည်းမျဉ်းမတူညီသော protocol တစ်ခုတည်း ဖြစ်သည်** — ၎င်းခြားနားချက်များသည် eBGP သည် ယုံကြည်မှုနယ်နိမိတ် (trust boundary) ကို ဖြတ်သန်းရပြီး iBGP မှာမူ မဖြတ်သန်းရဟူသော အချက်မှ ဆင်းသက်လာခြင်း ဖြစ်သည်။

| အချက်အလက် | eBGP | iBGP |
|---|---|---|
| မည်သူတို့ကြားတွင် | မတူညီသော AS များကြား | တူညီသော AS အတွင်း |
| ချိတ်ဆက်သည့် IP | Interface addresses | **Loopbacks** |
| Default TTL | 1 (တိုက်ရိုက်ချိတ်ထားသည်ဟု ယူဆ) | ပုံမှန်အတိုင်း |
| AS path | ကြေညာချိန်တွင် **မိမိ AS ကို ရှေ့မှ ထည့်သည်** | မပြောင်းလဲပါ |
| ပြန်လည်ကြေညာခြင်း | မည်သူ့ကိုမဆို | **အခြား iBGP peer ထံသို့ လုံးဝ ပြန်မကြေညာပါ** |
| Next hop | မိမိကိုယ်တိုင်ဟု သတ်မှတ်သည် | **မပြောင်းလဲဘဲ မူလအတိုင်း ထားသည်** ← Lab 01 ၏ ထောင်ချောက် |

နောက်ဆုံးစာကြောင်းသည် အစပြုသူများ အဖြစ်အများဆုံး အမှားဖြစ်သောကြောင့် Lab 01 တွင် ၎င်းကို ကြိုတင်သတိပေးမည့်အစား ရည်ရွယ်ချက်ရှိရှိ ကြုံတွေ့စေရန် ပြုလုပ်ထားပါသည်။
