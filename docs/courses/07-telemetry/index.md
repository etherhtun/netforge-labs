# Phase 7 · Telemetry & Observability

📖 **Status: Planned**

## Syllabus

This phase covers how to monitor hyper-scale networks, moving away from legacy SNMP polling.

- **Streaming Telemetry:** Using gNMI and OpenConfig.
- **Prometheus & Grafana:** Building a modern SRE monitoring stack.
- **Traffic Generation:** Validating network capacity and behavior using TRex.
