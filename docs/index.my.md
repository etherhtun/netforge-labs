# NETFORGE LABS

**ကွန်ရက်နည်းပညာကို လက်တွေ့ကိုယ်တိုင် တည်ဆောက်ရင်း ကျွမ်းကျင်အောင် လေ့လာပါ။** Arista cEOS ပေါ်တွင် စစ်မှန်သော network fabrics များကို ကိုယ်တိုင် deploy လုပ်ပါ၊ ပြဿနာရှာဖွေဖြေရှင်းနည်း (troubleshooting) သဘောပေါက်စေရန် ရည်ရွယ်ချက်ရှိရှိ စနစ်ကို ဖြတ်တောက်စမ်းသပ်ပါ၊ config တွေကို copy-paste ချရုံတင် မဟုတ်ဘဲ command တစ်ကြောင်းချင်းစီ ဘာကြောင့် ရေးရသလဲ (*why*) ဆိုသည့် အဓိက သဘောတရားကို အခြေခံကျကျ နားလည်စေမည်။

မိမိတက်လှမ်းလိုသည့် အင်ဂျင်နီယာ အထူးပြုလမ်းကြောင်းများကို အဆင့်လိုက် ရွေးချယ်လေ့လာနိုင်ပါသည် — **AI & Hyperscale Architecture**၊ **Network SRE & Observability**၊ **Cybersecurity & DevSecOps**၊ **NetDevOps**၊ **Low-Latency Finance** သို့မဟုတ် **TPM System Design**။

## 💡 Lab တစ်ခုချင်းစီ လေ့ကျင့်တည်ဆောက်ပုံ (How Every Lab Works)

သင်ခန်းစာ ခေါင်းစဉ်တိုင်းကို စနစ်ကျသော အင်ဂျင်နီယာ လေ့ကျင့်ရေးအဆင့်များအတိုင်း ဖွဲ့စည်းထားပါသည် -

**အယူအဆ (Mental Model) → ဘာကြောင့်သုံးရသလဲ (Why before How) → Protocol သဘောတရား → ကိုယ်တိုင်တည်ဆောက်ခြင်း → မှန်ကန်ကြောင်း စစ်ဆေးခြင်း → စနစ်ကို ချို့ယွင်းအောင် ဖြတ်တောက်စမ်းသပ်ခြင်း (Break it) → အင်တာဗျူး အမေးအဖြေ လေ့ကျင့်ခြင်း။**

Lab များအားလုံးတွင် **စံသတ်မှတ်ထားသော Single-source-of-truth config snippets များ**၊ **အလိုအလျောက် run စစ်ဆေးပေးသည့် step runner scripts (`run.sh`)** နှင့် **containerlab တိုက်ရိုက် gate checks စနစ်များ** ပါဝင်ပါသည်။
